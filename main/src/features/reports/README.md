# Reports Feature

## Purpose

Content reporting system. Allows users to report inappropriate content, comments, or reviews.

## API Endpoints

- `POST /api/reports` - Create a report

## Components

None (reporting is typically done via dialogs or forms)

## Hooks

None (reports are typically created via direct API calls or mutation hooks)

## Integration Points

- Content moderation
- User safety
- Report inappropriate content
- Admin moderation dashboard
