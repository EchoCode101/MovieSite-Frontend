# Search Feature

## Purpose

Global search functionality. Provides search across videos, users, movies, TV shows, and episodes.

## API Endpoints

- `GET /api/search` - Global search with optional type filter

## Components

None (search is typically implemented in a search bar component)

## Hooks

None (search is typically implemented via direct API calls or custom hooks)

## Integration Points

- Search bar in header/navbar
- Search results page
- Content discovery
- User search
