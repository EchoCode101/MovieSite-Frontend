# Video Metrics Feature

## Purpose

Video analytics and metrics. Provides access to video performance metrics like views, watch time, etc.

## API Endpoints

- `GET /api/video_metrics` - Get video metrics

## Components

None (metrics are typically displayed in admin dashboards or analytics pages)

## Hooks

- `useVideoMetrics()` - Fetch video metrics

## Integration Points

- Admin analytics dashboard
- Video performance tracking
- Content analytics
- View statistics
