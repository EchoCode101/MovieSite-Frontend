# Banners Feature

## Purpose

Banner management for displaying promotional content across different device types and page positions.

## API Endpoints

- `GET /api/banners` - Get banners with optional filters (device, position)

## Components

None (banners are typically displayed in layout components)

## Hooks

- `useBanners(params)` - Fetch banners with optional device and position filters

## Integration Points

- Home page banners
- Movie/TV show detail page banners
- Video player banners
- Device-specific banner display (web, mobile, TV)
